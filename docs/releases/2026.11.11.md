# OpenClaw v2026.11.11

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.11.md).

OpenClaw 2026.11.11 is a patch release focused on reliability across updates, backups, models, and messaging. It also resolves issues in the Web UI, automations, plugins, browser handling, and security.

**Release scale:** 68 pull requests, 5 direct commits, and 32 contributors.

## Installation and Onboarding

- Fixes Docker Compose CLI config and channel commands failing while the Gateway is running by sharing the Gateway process namespace, and preserves saved Docker sandbox settings during setup upgrades.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  If you define a custom Docker Compose CLI service, share the Gateway process namespace alongside its network namespace so state writes can verify Gateway ownership.

  [#202288](https://github.com/openclaw/openclaw/pull/202288).

  Thanks [@deepujain](https://github.com/deepujain), [@sallyom](https://github.com/sallyom), [@RomneyDa](https://github.com/RomneyDa), and [@vincentkoc](https://github.com/vincentkoc).

  </details>

- Fixes non-interactive Linux onboarding with `--install-daemon` modifying config, creating a workspace, or running `--reset` before failing when user-systemd services are unavailable.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  Onboarding now checks user-systemd availability up front and prompts you to rerun with `--skip-daemon` or retry from a working user-systemd session.

  [#204378](https://github.com/openclaw/openclaw/pull/204378).

  Thanks [@jjjhenriksen](https://github.com/jjjhenriksen).

- Fixes pnpm installations previously updated with `openclaw update` failing with exit code 1 after activating a later same-schema release. If you are upgrading from v2026.11.10 and hit this once, run `openclaw update repair` to clear it so future updates finish cleanly.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  Installations already on v2026.11.10 still hit exit code 1 once while updating to v2026.11.11 because the installed v2026.11.10 updater runs that hop.

  [#205078](https://github.com/openclaw/openclaw/pull/205078).

  Thanks [@fuller-stack-dev](https://github.com/fuller-stack-dev).

  </details>

- Stops read-only `openclaw doctor --lint` checks and `openclaw update status` from copying the shared SQLite database while a live Gateway owns it, preventing heavy disk I/O and session slowdowns.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  Offline inspection still uses private snapshots to preserve SQLite recovery files, and opt-in checks that initialize plugins still run against disposable writable state.

  [#205108](https://github.com/openclaw/openclaw/pull/205108).

  Thanks [@steipete](https://github.com/steipete).

  </details>

- Fixes Windows updates failing post-install verification with `EBUSY` when the agent or state SQLite database is larger than 1 GiB.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  Verification now hashes SQLite's unused 512-byte lock page at the 1 GiB boundary as zeros instead of reading locked bytes, keeping digests compatible with existing backups and receipts.

  [#205668](https://github.com/openclaw/openclaw/pull/205668).

  Thanks [@RomneyDa](https://github.com/RomneyDa).

  </details>
